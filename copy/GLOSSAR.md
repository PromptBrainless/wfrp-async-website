# Glossar — Die Frist

Kurze Wörter, immer dieselben. Keine Synonyme.

| Wort | Was es ist | Nicht |
|------|------------|--------|
| **Frist** | Die Zeit, bis alle gehandelt haben dürfen. Kein Zug. | Runde, Turn, Timer |
| **Faden** | Das Leben. Was im Tisch steht. | Chat, Log, Feed |
| **Blatt** | Der Bogen des Charakters. | Character sheet, Stats |
| **Pult** | Nur Spielleiter. Trigger, Lagen, Ziehen. | GM-Screen, Backend |
| **Tisch** | Die offene Szene. | Map, VTT, Board |
| **Absicht** | Was der Spieler tun will, bevor der Wurf fällt. | Intention, Action, Move |
| **Grau** | Die Karte bleibt sichtbar, geht aber nicht. Der Grund steht drauf. | disabled, locked |
| **Hub** | Die Kampagnen-Türen. Nur geöffnete Orte. | Lobby, Menü |
| **Wurfplatte** | Ziel, Wurf, EG, Band. Sichtbar, nachvollziehbar. | Dice chat |
| **Kartenleiste** | Die Handlungen unten. | Hotbar |
| **Leben** | Der Faden, öffentlich oder privat. | Chatfenster |
| **Gasse** | Offene Szene draußen. | Street map |
| **Lage** | Was Umschauen hergibt: grob, teil, voll, scharf. | Perception DC |

Regelwerk-Wörter aus dem Buch bleiben, wie Ulisses sie setzt: Fertigkeiten, Talente, EG, Glück, Mut, Schicksal, Zähigkeit, gebunden, Sturmangriff.

Spieler sehen die Lage, die ihr Wurf trägt. Der Spielleiter sieht alle Lagen plus die Notiz **Nur du**.
