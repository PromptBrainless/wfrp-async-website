# Angreifen, Trefferzonen & Schaden

Quelle: S. 158–160

## Standard-Schwierigkeit im Kampf
Herausfordernd (+0), sofern nicht anders angegeben.

## 1. Trefferwurf
- **Nahkampf:** Vergleichender Nahkampf-Wurf (beide auf KG). Gewinner erhält +1 Vorteil. Differenz der EG = finale EG.
- **Fernkampf:** Fernkampf-Wurf. Bei Erfolg +1 Vorteil. Gegner erhält keine Vorteile.

## 2. Trefferzone bestimmen
Würfelergebnis umkehren und mit Trefferzonen-Tabelle vergleichen.

| Wurf | Trefferzone |
|------|-------------|
| 01–09 | Kopf |
| 10–24 | Linker Arm (oder nichtdominanter) |
| 25–44 | Rechter Arm (oder dominanter) |
| 45–79 | Körper |
| 80–89 | Linkes Bein |
| 90–00 | Rechtes Bein |

## 3. Schaden bestimmen
Schaden = Waffenschaden + EG

## 4. Schaden abhandeln
LP-Verlust = Schaden − (Widerstands-Bonus + Rüstungspunkte der Trefferzone)  
Minimum 1 LP, sofern Schaden > 0.

Wenn LP-Verlust die verbliebenen LP übersteigt → Kritische Verletzung + Zustand *Niedergestreckt*.

## Gebunden
Sobald man sich im Nahkampf gegenseitig attackiert, gelten beide als gebunden.
