# Krankheiten und Infektionen

Quelle: S. 186–189

## Krankheits-Format
- Name
- Beschreibung
- Übertragung
- Inkubationszeit
- Dauer
- Symptome
- Permanente Folgen (optional)

## Wichtige Krankheiten (Auswahl)

| Krankheit | Übertragung | Symptome (Auszug) |
|-----------|-------------|-------------------|
| Blutfäule | Folge anderer Krankheit / Kritischer Verletzung | Fieber (schwerwiegend), Siechtum, Unwohlsein |
| Blutschiss | Infiziertes in den Mund (+40 WI-Wurf) | Durchfall (schwerwiegend), Fieber, Übelkeit |
| Galoppierender Durchfall | Infiziertes in den Mund | Durchfall (moderat), Übelkeit, Unwohlsein |
| Juckende Pocken | Kontakt / Husten (+20 Ausdauer) | Husten und Niesen, Pocken |
| Leichte Infektion | Nach Kritischer Verletzung (+60 Ausdauer) | Langanhaltend, Offene Wunde, Unwohlsein |
| Rattenfieber | Nager / Infiziertes | Fieber, Krämpfe, Offene Wunde, Pocken |
| Schwärende Wunde | Infizierte Kreatur / Folge | Fieber, Offene Wunde, Unwohlsein |
| Schwarze Pest | Flöhe / Flüssigkeiten | Beulen, Fieber, Siechtum, Wundbrand |
| Treiberpocken | Tiere / Häute | Langanhaltend, Pocken |

## Symptome (Kern)

- **Beulen**: −10 körperlich + Charisma
- **Durchfall**: SL-ansagen, bei schwerwiegend LP-Verlust
- **Fieber**: −10; schwerwiegend → *Bewusstlos*
- **Husten und Niesen**: verbreitet Krankheit
- **Krämpfe**: −10 / −20 / bewegungsunfähig
- **Langanhaltend**: Ausdauer-Wurf am Ende → Verlängerung oder Verschlimmerung
- **Offene Wunde**: 1 LP heilt nicht; Risiko auf Schwärende Wunde
- **Pocken**: −10 Charisma + Jucken
- **Siechtum**: täglicher Ausdauer-Wurf oder Tod
- **Übelkeit**: bei misslungenem körperlichem Wurf → *Betäubt*
- **Unwohlsein**: *Erschöpft*
- **Wundbrand**: täglicher Ausdauer-Wurf → mögliche Amputation
