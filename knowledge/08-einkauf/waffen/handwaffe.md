# Handwaffe

Quelle: S. 294, 296

Oberbegriff für alle einhändigen Standardwaffen, die sich unterscheiden, nach den Regeln aber identisch funktionieren: Schwerter, Äxte, Hämmer, Streitkolben, kurze Speere und mehr.

| Feld | Wert |
|------|------|
| Gruppe | Standard |
| Preis | 1 GK |
| TP | 1 |
| Verfügbarkeit | Verbreitet |
| Länge | Durchschnitt (bis 1 m) |
| Schaden | +STB+4 |
| Qualitäten / Makel | — |

Nicht -Startausrüstung. Katalog erlaubt sie, sobald jemand eine führt.

### Befehl

- `angreifen` mit gezogener `handwaffe`
- `waffe_ziehen`
