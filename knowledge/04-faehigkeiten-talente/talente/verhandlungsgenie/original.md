**Verhandlungsgenie**

**Maximum:** Charisma-Bonus  
**Würfe:** Feilschen

Du bist ein erfahrener Geschäftsmann und weißt, wie man einen Handel angeht. Wenn du die Fähigkeit Feilschen einsetzt, kannst du den Preis des Produktes um zusätzliche 10% erhöhen oder senken. Anmerkung: Der SL kann bezüglich Preisen ein Limit verhängen, welches verhindert, dass ein Verkäufer etwas unterhalb der eigenen Kosten verkauft. IV 146 DU WIRST STERBEN! Die folgenden Beispiele für Unkenrufe sollen dich dazu inspirieren, dir einen passenden auszudenken, wenn du das Talent Unkenruf hast. 0 Aus dem Dunkel nahet der Rabe. 0 Die Bestie auf dem Felde erblicket dich. 0 Seuche und dunkle Krankheit bringen dich auf die Knie. 0 Verlust lässt das Herz schwächer werden. 0 Das Schwert wird keine Gerechtigkeit bringen, einzig dein Ende. 0 Das Brot! Die Pastete! Der Kuchen! Sie sind auf Morrs Tisch für dich gedeckt. 0 Die Trommel wird dein Ende begleiten. 0 Dein Ende wird nicht dein Ende sein. 0 Du wirst einen tiefen Schluck aus dem Becher der Korrumpierung nehmen. 0 Hohe Orte bringen einen tiefen Fall.
